### 一、申請の背景

ギア 様

はじめまして。まずは「ポーズ集 POSE-DB-01」という質の高いポーズ素材集を公開してくださり、
誠にありがとうございます。顔なしグレーマネキンの線画は、AI 绘画における
ポーズ参照・構図参照として非常に有用であり、また貴サイトにて
「作品制作での商用利用・編集・参考利用 OK」と明記されていることを拝見いたしました。

私は ComfyUI のユーザーであり、ツール開発者でもあります。AI 绘画のワークフローを
日常的に使う中で、「ブラウザで画像を選んで ComfyUI にドラッグする」という作業が
煩雑に感じられました。そこで、**ComfyUI 内で直接ポーズ素材を閲覧・呼び出せる**
カスタムノードプラグインを開発いたしました。

開発にあたり、以下の原則を厳守しております：

1. **貴素材のファイルを複製・再配布いたしません**。プラグイン自体に画像は含まれません。
2. プラグインは、ユーザーの**ローカルに既に存在する**素材ファイルを読み込むだけであり、
   ローカルの画像ビューアに近い性質のものです。
3. プロジェクトのドキュメントに**素材の出典と貴名を明記**し、
   素材の著作権が貴殿に帰属することを明示しております。
4. 「原作者からの異議があれば、直ちに調整または公開停止する」旨を明記しております。

本プロジェクトは GitHub でのオープンソース公開を予定しており、
貴素材の「引用・関連利用」に該当する可能性があるため、
コンプライアンス確保と貴殿のご意向尊重のため、正式に申請いたします。

### 二、申請事項

### 三、当方の約束事項

ご許諾いただいた場合、以下を厳守いたします：

1. **素材の再配布は一切行いません**
   GitHub リポジトリ、Release、クラウドストレージ等に、
   素材画像や素材インデックスデータをアップロードいたしません。
   利用者は貴サイトからご自身で素材を取得する必要があります。

2. **クレジットとリンク**
   `README.md`、`ATTRIBUTION.md`、および ComfyUI ノード画面に以下を明記します：
   > 素材出典：ポーズ集 POSE-DB-01 ／ 作者：ギア ／ <https://ai-pose-gallery.pages.dev/>

3. **「非公式」の明示**
   本プロジェクトが第三者による非公式ツールであり、貴殿と関係がないことを明記します。

4. **素材内容の不改変**
   プラグインは元ファイルを読み込むのみで、改変・トリミング・透かし・再エンコードを行いません。

5. **撤回権の尊重**
   貴殿はいつでも X のDM または GitHub Issue にて許諾の撤回を通知できます。
   当方は通知受領後 **72 時間以内**に修正または公開停止を行い、再公開いたしません。

6. **不適切な用途への不使用**
   公序良俗に反する用途、実在人物や未成年を表す用途には使用せず、
   利用者にも同様の制約を守るよう促します。
